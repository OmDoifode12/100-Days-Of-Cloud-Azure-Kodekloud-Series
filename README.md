# 📖 About This Repository

This repository documents my complete journey through the **100 Days of Cloud (Azure) Challenge** with **KodeKloud**.

Over 100 consecutive days, I completed hands-on Azure labs covering cloud infrastructure, networking, storage, security, monitoring, automation, containers, Kubernetes, databases, and real-world troubleshooting scenarios.

The goal of this challenge was not just to learn Azure services, but to understand how cloud infrastructure works in real-world environments through practical implementation and problem-solving.

Every task includes:

- Problem Statement
- Azure CLI Commands
- Resource Configuration
- Deployment Steps
- Troubleshooting Process
- Validation Checks
- Key Learnings
- Production Use Cases
