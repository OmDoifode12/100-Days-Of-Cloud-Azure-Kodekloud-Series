# Day 47: Azure SQL Database Migration and Setup

## 📌 Objective

Deploy an Azure SQL Database, configure Azure Blob Storage for database backups, export the database as a BACPAC file, and download the backup to the client machine for migration and recovery purposes.

---

## 🏗️ Architecture

```text
                Azure SQL Server
                       │
                       ▼
             Azure SQL Database
                       │
                Export (.bacpac)
                       │
                       ▼
          Azure Blob Storage Container
                       │
                       ▼
          Download to Azure Client (/opt)
```

---

## ⚙️ Prerequisites

- Azure CLI
- Existing Resource Group
- Azure Subscription
- Azure Portal Access

---

## 🚀 Step 1: Get Resource Group

```bash
RG_NAME=$(az group list --query "[0].name" -o tsv)

echo $RG_NAME
```

---

## 🚀 Step 2: Create Storage Account

```bash
az storage account create \
-g $RG_NAME \
-n nautilusst2941 \
-l westus \
--sku Standard_LRS
```

---

## 🚀 Step 3: Get Storage Account Key

```bash
ACCOUNT_KEY=$(az storage account keys list \
-g $RG_NAME \
-n nautilusst2941 \
--query "[0].value" \
-o tsv)
```

---

## 🚀 Step 4: Create Blob Container

```bash
az storage container create \
--account-name nautilusst2941 \
--account-key "$ACCOUNT_KEY" \
--name nautilus-container-21028
```

---

## 🚀 Step 5: Create Azure SQL Server

```bash
az sql server create \
-g $RG_NAME \
-n nautilus-server-31792 \
-l westus \
-u nautilus-admin \
-p 'Namin@123456'
```

---

## 🚀 Step 6: Allow Azure Services

```bash
az sql server firewall-rule create \
-g $RG_NAME \
-s nautilus-server-31792 \
-n AllowAzure \
--start-ip-address 0.0.0.0 \
--end-ip-address 0.0.0.0
```

---

## 🚀 Step 7: Create Azure SQL Database

```bash
az sql db create \
-g $RG_NAME \
-s nautilus-server-31792 \
-n nautilus-sqldb \
--service-objective Basic \
--backup-storage-redundancy Local \
--max-size 2GB
```

---

## 🚀 Step 8: Verify Database Status

```bash
az sql db show \
-g $RG_NAME \
-s nautilus-server-31792 \
-n nautilus-sqldb \
--query status
```

Expected Output:

```text
Online
```

---

## 🚀 Step 9: Export Database (Azure Portal)

Navigate to:

```text
Azure SQL Database
      ↓
nautilus-sqldb
      ↓
Export
```

Configure:

| Setting | Value |
|----------|-------|
| Storage Account | `nautilusst2941` |
| Container | `nautilus-container-21028` |
| File Name | `nautilus-db-backup.bacpac` |
| Login | `nautilus-admin` |
| Password | `Namin@123456` |

Click **OK** and wait for the export to complete.

> **Important:** Use the exact filename `nautilus-db-backup.bacpac`. Do not use the autogenerated filename.

---

## 🚀 Step 10: Verify Backup in Blob Storage

```bash
az storage blob list \
--account-name nautilusst2941 \
--account-key "$ACCOUNT_KEY" \
--container-name nautilus-container-21028 \
-o table
```

Expected Output:

```text
nautilus-db-backup.bacpac
```

---

## 🚀 Step 11: Download Backup

```bash
az storage blob download \
--account-name nautilusst2941 \
--account-key "$ACCOUNT_KEY" \
--container-name nautilus-container-21028 \
--name nautilus-db-backup.bacpac \
--file /opt/nautilus-db-backup.bacpac
```

---

## 🚀 Step 12: Verify Download

```bash
ls -lh /opt/nautilus-db-backup.bacpac
```

Expected Output:

```text
/opt/nautilus-db-backup.bacpac
```

---

## ✅ Validation Checklist

- Azure SQL Server created
- Azure SQL Database created
- Database status is **Online**
- Storage Account created
- Blob Container created
- Database exported successfully
- Backup file stored as `nautilus-db-backup.bacpac`
- Backup downloaded to `/opt`
- Database backup ready for migration or recovery

# ⚠️ Troubleshooting

### Issue

Exported backup failed validation because the filename was autogenerated.

### Solution

Rename the export during the Azure Portal export process to:

```text
nautilus-db-backup.bacpac
```

This exact filename is required for automated validation.

# 🎯 Key Learnings

- Azure SQL Database provides a fully managed relational database service.
- Azure Blob Storage is commonly used for storing SQL database backups.
- BACPAC files are used for database migration, backup, and recovery.
- Azure SQL Export simplifies moving databases between environments.
- Correct resource configuration and naming conventions are critical for successful cloud automation and migration.
