# Day 46: EventHub to Blob Storage Integration Setup

## 📌 Objective

Integrate Azure Event Hubs with Azure Blob Storage using a Virtual Machine to build a centralized log collection and backup solution. Logs generated by a Python application are streamed to Event Hub and simultaneously backed up to Azure Blob Storage.

---

## 🏗️ Architecture

```text
                 Azure Virtual Machine
                         │
                  Python send_logs.py
                         │
         ┌───────────────┴────────────────┐
         │                                │
         ▼                                ▼
 Azure Event Hub                  Azure Blob Storage
         │                                │
         ▼                                ▼
 Event Hub Metrics              logs.txt Backup File
```

---

## ⚙️ Prerequisites

- Azure CLI
- Existing Resource Group
- SSH Key Pair
- Python 3
- Azure Storage Blob SDK
- Azure Event Hub SDK

---

## 🚀 Step 1: Get Resource Group

```bash
RG_NAME=$(az group list --query "[0].name" -o tsv)

echo $RG_NAME
```

---

## 🚀 Step 2: Create Event Hub Namespace

```bash
az eventhubs namespace create \
-g $RG_NAME \
-n nautilus-namespace \
-l eastus \
--sku Standard \
--enable-auto-inflate true \
--maximum-throughput-units 2
```

---

## 🚀 Step 3: Create Event Hub

```bash
az eventhubs eventhub create \
-g $RG_NAME \
--namespace-name nautilus-namespace \
-n nautilus-hub
```

---

## 🚀 Step 4: Create Storage Account

```bash
az storage account create \
-g $RG_NAME \
-n nautilusst17016 \
-l eastus \
--sku Standard_LRS
```

---

## 🚀 Step 5: Enable Blob Public Access

```bash
az storage account update \
-g $RG_NAME \
-n nautilusst17016 \
--allow-blob-public-access true
```

---

## 🚀 Step 6: Get Storage Account Key

```bash
ACCOUNT_KEY=$(az storage account keys list \
-g $RG_NAME \
-n nautilusst17016 \
--query "[0].value" \
-o tsv)
```

---

## 🚀 Step 7: Create Blob Container

```bash
az storage container create \
--account-name nautilusst17016 \
--account-key "$ACCOUNT_KEY" \
--name nautilus-backup-29856 \
--public-access blob
```

---

## 🚀 Step 8: Create Virtual Machine

```bash
az vm create \
-g $RG_NAME \
-n nautilus-vm \
--image Ubuntu2204 \
--size Standard_B1s \
--admin-username azureuser \
--generate-ssh-keys
```

---

## 🚀 Step 9: Get VM Public IP

```bash
VM_IP=$(az vm show -d \
-g $RG_NAME \
-n nautilus-vm \
--query publicIps \
-o tsv)

echo $VM_IP
```

---

## 🚀 Step 10: Copy Python Script

```bash
scp /root/send_logs.py azureuser@$VM_IP:/home/azureuser/
```

---

## 🚀 Step 11: SSH into VM

```bash
ssh azureuser@$VM_IP
```

---

## 🚀 Step 12: Install Required Python Packages

```bash
pip3 install azure-eventhub azure-storage-blob
```

---

## 🚀 Step 13: Configure Python Script

Update:

- Event Hub Connection String
- Event Hub Name
- Blob Storage Connection String
- Blob Container Name

The script should:

- Send logs to Event Hub
- Upload logs.txt to Azure Blob Storage

---

## 🚀 Step 14: Execute Script

```bash
python3 /home/azureuser/send_logs.py
```

Run multiple times:

```bash
python3 /home/azureuser/send_logs.py
python3 /home/azureuser/send_logs.py
python3 /home/azureuser/send_logs.py
python3 /home/azureuser/send_logs.py
python3 /home/azureuser/send_logs.py
```

Expected Output

```text
Log sent to Event Hub and backed up to Blob Storage.
```

## 🚀 Step 15: Verify Blob Backup

```bash
az storage blob list \

--account-key "$ACCOUNT_KEY" \
```

# ⚠️ Troubleshooting

### Error

```text
Auto inflate MaximumThroughputUnits 'not specified' is out of range
```

### Fix

```bash
--maximum-throughput-units 2
```

---

### Error

```text
ContainerNotFound
```

### Fix

- Enable Blob Public Access
- Refresh Storage Account Key
- Recreate the Blob Container

---

### Error

```text
AuthorizationRuleNotFound
```

### Fix

Retrieve the namespace connection string instead of the Event Hub authorization rule:

```bash
az eventhubs namespace authorization-rule keys list
```
